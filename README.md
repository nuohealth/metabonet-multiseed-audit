# Multi-seed Robustness Auditing of Recurrent Architectures for Blood Glucose Forecasting

**A 20-seed robustness benchmark on the MetaboNet cohort (n = 1,092)**

[![DOI](https://img.shields.io/badge/DOI-10.XXXX/XXXXXXXX-red)](https://doi.org/PENDING)

## Overview

This repository contains the full, reproducible implementation for the manuscript **"Multi-seed robustness auditing of recurrent architectures for blood glucose forecasting"** (submitted to *PLOS ONE*).

We benchmark four recurrent architectures — a plain **LSTM**, a **BiLSTM**, an **LSTM + additive attention**, and a **BiLSTM-Attention** hybrid — for 30-minute-ahead blood glucose forecasting from CGM alone, across **20 independent training seeds** on the public [MetaboNet](https://metabo-net.org) T1D resource (3,135 subjects; a filtered analysis cohort of 1,092), with cross-cohort replication on a T2D cohort (100 subjects).

**Key finding:** Added architectural complexity yields no clinically meaningful improvement (max ΔRMSE = 0.065 mg/dL, far below the 5 mg/dL clinical threshold), while within-architecture seed variation (SD 0.054–0.074 mg/dL) is of the same order as between-architecture differences. A simple LSTM is a sufficient, defensible baseline for short-horizon univariate glucose forecasting.

## Quick start

```bash
# 1. Environment
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Data
# Download MetaboNet v2.0 from https://metabo-net.org into data/metabonet_v2/
#   (T1D primary, n=1,092) and the Shanghai T1DM/T2DM datasets [25]
#   (doi:10.1038/s41597-023-01940-7) into data/t2d/  (T2D validation, n=100)

# 3. Train 4 architectures x 20 seeds (T1D primary)
python src/train_20seed_serial.py

# 4. Cross-cohort validation (T2D)
python src/train_20seed_serial_t2d.py

# 5. Statistics
python src/statistical_tests_20seed.py
python src/statistical_tests_cross_cohort.py

# 6. Clinical evaluation
python src/clinical_evaluation.py

# 7. Regenerate figures
python make_figures.py
```

## Reproducibility notes

- **Fixed seed range:** seeds 42–61 (20 seeds) for every architecture, both cohorts.
- **Pipeline fixed:** training only varies architecture; hyperparameters/horizon (30 min) are constant.
- **Statistical tests:** paired t-test, Wilcoxon signed-rank, Diebold–Mariano, Cohen's d, with Holm–Bonferroni multiple-comparison correction across the 6 pairwise contrasts.
- **Clinical metrics:** Clarke error-grid analysis, MARD, per-horizon ±20% accuracy, stratified RMSE, hypoglycaemia detection (sensitivity/specificity/PPV).

## Data

MetaboNet v2.0 is the largest publicly available consolidated CGM dataset for T1D (1,092 subjects), multi-centre, real-world. Download: <https://metabo-net.org> (dataset paper: MetaboNet, *J Diabetes Sci Technol*, 2026).
